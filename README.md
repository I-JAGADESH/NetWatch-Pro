# NetWatch Pro

## Overview

NetWatch Pro is a Python-based network monitoring system that continuously checks device availability and latency.

## Features

* Real-time device monitoring
* Latency tracking
* Continuous monitoring
* Device uptime statistics
* Network logging
* Summary report generation
* Interactive CLI dashboard

## Technologies Used

* Python
* OOP (Object-Oriented Programming)
* Ping3
* Colorama
* File Handling
* Exception Handling

## Project Structure

NetWatch-Pro/

├── main.py

├── devices.txt

├── requirements.txt

├── README.md

├── logs/

└── core/

## How to Run

Install dependencies:

pip install -r requirements.txt

Run:

python main.py
